# Rustlings

This repository contains my personal solutions to all the [Rustlings](https://github.com/rust-lang/rustlings) exercises, completed as part of my journey learning Rust.

## About Rustlings

Rustlings is an official set of small, interactive exercises created by the Rust community to help beginners practice reading and writing Rust code. It provides instant feedback, helpful hints, and a structured path through the language fundamentals.

I've successfully completed every exercise! 🎉 Feel free to browse my solutions if you're stuck or just curious about different approaches.
